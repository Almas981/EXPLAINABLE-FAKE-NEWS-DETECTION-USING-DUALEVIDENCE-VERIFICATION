# EXPLAINABLE-FAKE-NEWS-DETECTION-USING-DUALEVIDENCE-VERIFICATION
Explainable News Verifier checks a claim against retrieved evidence and returns a verdict (supporting, refuting, conflicting, or insufficient) with the exact sentences behind it. It uses BM25+BGE hybrid retrieval, RRF, cross-encoder reranking, a FEVER-tuned DeBERTa-v3 NLI model, calibrated confidence, and a named-subject guard.
